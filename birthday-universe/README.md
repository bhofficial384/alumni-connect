## 🌹 Special Features & Interactivity

1. **Floating Rose Petals & Click Hearts**: Delicate rose petals drift across the screen, and clicking anywhere spawns floating glowing hearts.
2. **Generative Romantic Music**: Soft, soothing piano & pad chords synthesized using the Web Audio API (100% offline, zero network or CORS issues) with a floating mute/unmute control.
3. **Live Relationship Counter**: Counts the exact days, hours, minutes, and seconds you've loved Anju.
4. **Secret 7-Clicks Easter Egg**: Tapping the glowing heart on the hero section 7 times unlocks a secret hidden love note from Saurabh.
5. **Personalization Workshop**: Click the ⚙️ icon in the bottom navigation bar to easily change names, relationship start date, upload personal photographs for the timeline and polaroids, and save everything locally.
